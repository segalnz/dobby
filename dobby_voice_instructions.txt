Context:
tts_kokoro.py uses kokoro-onnx to generate speech using voice bf_lily outputting a numpy float32 audio array at 24000Hz (Kokoro's native sample rate). This array is then passed to the audio sender. A sox post-processing step is to be inserted between Kokoro output and the audio sender.

Install sox on lama if not already present:
sudo apt install sox libsox-fmt-all

sox input.wav output.wav \
  pitch 300 \
  overdrive 8 3 \
  treble +4 3000 \
  rate 24000

Read the processed WAV back as a numpy array
Pass the processed array to the audio sender instead of the original


Set Kokoro inference parameters:


speed=1.1 — slightly faster delivery
Voice remains bf_lily
Language remains en-gb


Use distinct temp file paths for input and output WAV files to avoid file handle conflicts. Both should be cleaned up after the processed array is read back.

Sox subprocess must complete before the processed WAV is read back
Do not modify the audio sender or any downstream pipeline component
Do not change the Kokoro model path or voice selection elsewhere in the config
